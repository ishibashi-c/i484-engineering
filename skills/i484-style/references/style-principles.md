# 共通の好み

好みを設計に適用する前に読む。既存3領域の採用方向を集約したもので、新しいブランドや固定テーマを導入するものではない。

情報や主題の関係を構成へ反映する。主役、支える要素、境界、反復、比較軸を読める形にし、無関係な題材へ内容だけ差し替えて成立する汎用テンプレートへ押し込まない。

文字は内容と階層を伝える主要な手段にする。余白、整列、尺度、近さで構造を作り、囲み、影、角丸、装飾は分類・操作・意味のある境界を伝える場合に使う。同じ役割の表現は安定させる。

色には背景、主題、分類、状態、強調などの役割を与える。温度、彩度、面積比を調整し、重要な意味を色だけへ依存させない。UIの状態色とイラストの限定色は異なる目的を持つ。

明快な幾何学と、密度のある主題領域・視覚的に休める領域の対比を好む。UIでは中程度の情報密度を基準とし、重要な情報や操作を見える状態に保つ。資料では読む順序と比較を、イラストでは認識に必要な関係を優先する。

幾何学の好みは、UIや文書へイラストの形状文法を全面適用する指示ではない。必要な領域の具体的な規則と、今回のブランド・主題に合わせる。好みと一般品質は別々に評価し、基本品質が下がる場合は表現を調整する。
